# دليل الجيزة — Giza Guide

دليل صغير بالعربية والإنجليزية: أهرامات الجيزة، سقارة، دهشور والمتحف المصري الكبير. بحث باللغتين، تبديل اتجاه الواجهة وقائمة زيارة محفوظة محليًا. الأوصاف موجزة ومصادرها رسمية؛ المواعيد والتذاكر تؤخذ من الرابط الرسمي وقت الزيارة.

```sh
python -m http.server 8080 --bind 127.0.0.1
npm test
```

افتح http://127.0.0.1:8080. التطبيق مستقل بلا CDN أو حسابات أو خادم API؛ يحتاج تقديم الملفات محليًا، ولا يعد تخزين localStorage نسخة احتياطية أو مزامنة. رابط المصدر يحتاج اتصالًا بالإنترنت. لا خرائط أو حجز أو تتبع للموقع في هذه المرحلة.

روابط الأماكن روجعت في 2 أكتوبر2026. [المراجعة والأدلة](DEVELOPMENT_REVIEW_AR.md).

بعد أول فتح ناجح عبر HTTPS أو localhost، يحفظ المتصفح ملفات الدليل الستة؛ يمكنك إعادة فتحه والبحث باللغتين وتعديل قائمة الزيارة دون اتصال. انتظر رسالة «الدليل محفوظ للفتح دون اتصال» قبل الاعتماد على النسخة. روابط المصادر الرسمية تحتاج الإنترنت. إذا منع المتصفح الحفظ، يعرض رسالة واضحة ويبقى الدليل متاحًا أثناء الاتصال.

عند تنزيل نسخة أحدث يظهر «تحديث النسخة المحفوظة». النقر يفعّلها ويعيد فتح الصفحة مع الاحتفاظ بقائمة الزيارة؛ فشل التنزيل يُبقي النسخة السابقة. هذا الحفظ لا ينقل قائمة الزيارة إلى حساب أو نسخة احتياطية. لا يوجد إصدار متجر أو تثبيت Android في هذا المشروع.

للمطور: غيّر `VERSION` في `sw.js` كلما تغير أحد ملفات الدليل الستة. النطاق هو مجلد هذا المشروع فقط؛ لا تُخزّن الصفحات الخارجية أو المسارات المجهولة، ولا تُحذف cache التطبيقات المجاورة. [تصميم Service Workers وحدود السياق الآمن](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers).
